# 🛒 Lista de Compras

Um aplicativo simples em React Native e Expo para organizar suas compras do dia a dia.

## 🚀 Funcionalidades

* Adicionar produtos com nome e quantidade.

* Remover itens da lista.

* Validação para não adicionar itens sem nome.

* Contagem dinâmica de produtos no rodapé.

## 🛠️ Tecnologias

* React Native

* Expo

* TypeScript

## 💻 Como Rodar o Projeto

1. Instale as dependências:

```
npm install


```

2. Inicie o projeto:

```
npm start


```

3. Abra o aplicativo **Expo Go** no celular para escanear o QR Code, ou pressione `w` para testar no navegador web.
